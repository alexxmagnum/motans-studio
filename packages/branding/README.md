# @motanos/branding

Corporate brand assets for **Motans Studio** / **MotanOS**, vendored in this repository (`motans-studio-website`).

Package name `@motanos/branding` is a technical identifier — do not rename.

## Source of truth (this repo)

```text
packages/branding/public/motans/
  MotanOS.stamp.png
  motans-m.png
  motans-ms.webp
  motans-ms.png
```

Public site copies live under `public/brand/` when needed by Next.js.

Official identity (domain, email, legal): see `docs/BRANDING.md` and `lib/msSiteIdentityFoundation.ts`.
