# i18n

Objetivo: preparar la base compartida de idiomas y convenciones de internacionalizacion.

Que contiene ahora: codigos soportados, idioma por defecto, diccionario de traducciones y helper minimo de idioma.

Que no debe contener todavia: sistema i18n completo, catalogos grandes ni traducciones de producto.

Fase relacionada: `Fase 4 - Paquetes compartidos base` de los planes `04`, `06` y `07`.
